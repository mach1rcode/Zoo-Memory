# Zoo Match

A memory game with zoo animals for small children. Turn over two tiles to find a pair.

Play: https://mach1rcode.github.io/Zoo-Memory/

- Set the number of tiles from 4 to 24, in steps of 2.
- Soft sounds for a flip, a pair, and a finished game. The sound can be turned off.
- No timer and no score.

## Add to an iPhone Home Screen

1. Open the link above in Safari.
2. Tap Share, then "Add to Home Screen".

The game is one file, `index.html`. It needs no build step.
